```
┌─────────────────────────────────────────────────────────────────────────────┐
│                         HTTP Request                                        │
└──────────────────────────────────────┬──────────────────────────────────────┘
                                       │
                                       ▼
┌─────────────────────────────────────────────────────────────────────────────┐
│  Layer 1: Authentication (JWT Token Validation)                             │
│  ┌─────────────────────────────────────────────────────────────────────┐   │
│  │ Middleware: auth.go                                                  │   │
│  │                                                                      │   │
│  │ 1. Extract Bearer Token from Authorization Header                    │   │
│  │ 2. Parse & Validate JWT (signature, expiry)                         │   │
│  │ 3. Check Session Whitelist in Redis (session:access:{tokenID})      │   │
│  │ 4. Load User from DB (with Roles/Groups/Department)                 │   │
│  │ 5. Inject CurrentUser into gin.Context                              │   │
│  │                                                                      │   │
│  │ Failure → 401 Unauthorized                                           │   │
│  └─────────────────────────────────────────────────────────────────────┘   │
                                       │
                                       ▼ Pass
┌─────────────────────────────────────────────────────────────────────────────┐
│  Layer 2: API Authorization (Casbin RBAC)                                  │
│  ┌─────────────────────────────────────────────────────────────────────┐   │
│  │ Middleware: casbin.go                                                │   │
│  │                                                                      │   │
│  │ Extract: Method (GET/POST/...) + Path (/api/v1/pods)                 │   │
│  │                                                                      │   │
│  │ Enforcer.Enforce(role_codes[], path, method)                         │   │
│  │      ↓                                                               │   │
│  │ Casbin Model (RBAC):                                                 │   │
│  │   r = sub, obj, act                                                 │   │
│  │   p = sub, obj, act                                                 │   │
│  │   g = _, _  (role inheritance)                                       │   │
│  │   m = g(r.sub, p.sub) && r.obj == p.obj && r.act == p.act          │   │
│  │                                                                      │   │
│  │ Policy Example:                                                      │   │
│  │   p, admin, /api/v1/users, GET        ✅ Allow                       │   │
│  │   p, dev, /api/v1/pods, GET           ✅ Allow                       │   │
│  │   p, dev, /api/v1/pods, POST          ❌ Deny                        │   │
│  │                                                                      │   │
│  │ Failure → 403 Forbidden                                              │   │
│  └─────────────────────────────────────────────────────────────────────┘   │
                                       │
                                       ▼ Pass
┌─────────────────────────────────────────────────────────────────────────────┐
│  Layer 3: K8s Scope Authorization (Cluster-Level Access Control)           │
│  ┌─────────────────────────────────────────────────────────────────────┐   │
│  │ Middleware: k8s_scope_authorize.go (仅 K8s 路由生效)                │   │
│  │                                                                      │   │
│  │ Extract: cluster_id from Query/Body                                 │   │
│  │                                                                      │   │
│  │ Query k8s_cluster_access_grants:                                     │   │
│  │   WHERE principal_kind IN ('role', 'user')                           │   │
│  │   AND principal_ref IN (current_user_roles, current_user_id)         │   │
│  │   AND cluster_id = ?                                                │   │
│  │                                                                      │   │
│  │ Preset Levels:                                                       │   │
│  │   ┌─────────────┬───────────────────────────────────────────────┐    │   │
│  │   │ readonly    │ GET (list/detail/events/logs/files)            │    │   │
│  │   │ readonly_exec│ + Pod Exec, Terminal, Log Streaming          │    │   │
│  │   │ admin       │ + Apply/Create/Delete/Scale/Restart           │    │   │
│  │   └─────────────┴───────────────────────────────────────────────┘    │   │
│  │                                                                      │   │
│  │ Namespace Policy Filter:                                            │   │
│  │   1. Blacklist (Deny): Block specific namespaces                    │   │
│  │   2. Whitelist (Allow): Only allow specific namespaces             │   │
│  │   Priority: Deny > Allow (黑名单优先)                               │   │
│  │                                                                      │   │
│  │ Failure → 403 Forbidden (insufficient cluster access)               │   │
│  └─────────────────────────────────────────────────────────────────────┘   │
                                       │
                                       ▼ All Pass
┌─────────────────────────────────────────────────────────────────────────────┐
│                         Business Handler                                   │
└─────────────────────────────────────────────────────────────────────────────┘
```
