## 1. 日常运行

### 1.1 进程与端口

| 服务 | 容器名（compose） | 端口 |
|------|-------------------|------|
| 前端 | yunshu-frontend | 8083→80 |
| 后端 | yunshu-backend | 8080 |
| Redis | yunshu-redis | 6379 |

### 1.2 启停

见《系统部署实施方案》。生产建议：`restart: unless-stopped`（compose 已配）。

### 1.3 配置热更范围

- **多数** `config.yaml` 项需重启 backend。  
- Casbin：可配置 `auto_load_interval_seconds` 自动重载策略。  
- 字典项（Jenkins/邮件等）：多数运行时读取（以具体 `dictconfig` 实现为准）。

| 类型 | 位置/说明 |
|------|-----------|
| 应用 slog | 见 `docs/logging.md`（多文件/级别） |

## 3. 监控与健康

| 检查 | 方法 |
|------|------|
| 存活 | `GET /api/v1/health` |
| Redis | compose healthcheck：`redis-cli ping` |
| MySQL | 后端启动/entrypoint 等待；业务读写失败会打错误日志 |
| 后台 Worker | 各插件 StartWorkers；异常看 backend 日志关键字（jenkins sync、alert、backup、inspect、retention） |

建议监控：HTTP 5xx 率、接口延迟、Redis 内存、MySQL 连接数、磁盘、队列堆积（告警 webhook 队列配置项）。

## 4. 后台任务一览

| Worker | 插件 | 作用 |
|--------|------|------|
| Alert 评估/投递/云到期等 | alert | 告警主循环 |
| Jenkins 同步 | cicd | 构建/发布状态 |
| MySQL 备份调度 | backup | 定时备份 |
| 日志保留 / Kafka→ES | project | 索引清理与转发 |
| 实例探活 / SLA | dbmgmt | DB 连通性与审批提醒 |
| 巡检调度 | inspect | 约 30s tick |
| K8s Event Forward | k8s | 事件转发 |

关闭插件即停止对应 Worker。

## 5. 常见故障排查

### 5.1 无法登录 / 401

1. Redis 是否可达、密码是否匹配。  
2. JWT_SECRET 是否变更导致旧 token 无效。  
3. 用户 `status` 是否禁用。  
4. 查看 `login_logs`。

### 5.2 403 无权限

1. Casbin 策略 / 角色是否包含该 path+method。  
2. 是否项目成员；readonly 是否误调写接口。  
3. 服务器/CICD/DB 资源 ACL 是否授权。  
4. K8s：集群档位与 NS 黑白名单。

### 5.3 终端 / Pod Exec 失败

1. `ws-ticket` 是否成功；是否重复使用。  
2. Origin/Host 反代是否丢端口（见历史修复：`CheckOrigin` / nginx `Host`）。  
3. 服务器 `can_exec`；K8s exec 档位。

### 5.4 告警不通知

1. Webhook Token。  
2. 订阅树匹配标签。  
3. 渠道 URL 可达；出站禁止打到 localhost/元数据地址。  
4. Redis 异常可能导致去重状态异常（重复或漏聚）。  
5. 渠道超时 `default_timeout_ms`。

### 5.5 CI/CD 构建失败

1. Jenkins 连通与账号 Token（配置/字典）。  
2. 服务 Jenkins Job 名。  
3. 同步 worker 是否运行。  
4. 发布无审批流时是否由管理员审批。

### 5.6 SQL 工单无法提交

1. 项目是否配置启用审批阶段。  
2. goInception 仅支持 MySQL 直连。  
3. SQL 是否被 `sql_guard` 阻断。

## 6. 备份与恢复

| 对象 | 建议 |
|------|------|
| MySQL | 每日逻辑/物理备份；变更前额外快照 |
| Redis | 可丢（session/告警状态）；重要环境可开 AOF（当前 compose 默认关持久化） |
| 配置 | 备份 `.env`、`configs/`、字典敏感项流程 |
| MinIO 备份集 | 按 backup 插件任务保留策略 |

恢复：停写 → 还原 DB → 启动 backend → 验证 migrate 兼容性。

---

## 7. 账号与密钥轮换

1. 轮换 `JWT_SECRET`：全员重新登录。  
2. 轮换 `ENCRYPTION_KEY`：**需数据迁移方案**，不可随意更换。  
3. 轮换 Redis 密码：同步 `.env` 与 compose 后重启。  
4. 管理员密码：个人设置或用户管理；seed 不重置已有 admin。

---

## 8. 变更窗口操作单（模板）

1. 公告 → 2. 备份 → 3. 部署新版本 → 4. migrate/seed（按需）→ 5. 冒烟（登录/项目/告警 webhook/构建只读）→ 6. 观察日志 30min → 7. 关闭变更单。
