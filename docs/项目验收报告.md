## 1. 验收综述

本报告用于甲乙双方对 **Yunshu 当前代码交付物** 进行对照验收。  
功能范围以 `configs/config.yaml` 默认启用插件及对应实现为准，**不包含未实现能力**（见 SRS「不在交付范围」）。

### 1.1 交付物清单

| 类别 | 交付内容 | 位置 |
|------|----------|------|
| 源码 | 后端 Go + 前端 React | 仓库根目录 |
| 配置 | 应用/Casbin/环境样例 | `configs/`（以 `config.yaml` 为唯一纳管入口） |
| 容器 | Compose + Dockerfile | `docker-compose.yml`、`Dockerfile.backend`、`web/Dockerfile.frontend` |
| 运维附件 | Loggie 二进制、entrypoint | `deploy/` |
| 文档 | 需求/设计/DB/API/部署/运维/测试/验收 | `docs/` 本套交付文档 |
| 质量门禁 | CI Workflow | `.github/workflows/ci.yml` |

### 1.2 版本标识建议

## 4. 已知限制（甲方确认）

双方确认以下为 **已知限制/保留项**，不作为本版本缺陷拒收条件（除非合同另有约定）：

1. 前端无自动化测试；JWT 存 localStorage。  
2. 自审自批允许（审批组成员含提交人时）。  
3. goInception 不支持 PostgreSQL / SSH 隧道审核。  
4. 仓库未提供 Yunshu 自身完整 Helm Chart。  
5. OpenAPI 文件需验收前重新生成以对齐最新路由。
